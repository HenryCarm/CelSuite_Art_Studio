## 🌟 Overview

**CelSuite — Art Studio (CelAS)** is an offline, privacy-first generative AI studio designed to run directly on standard CPU hardware without needing expensive cloud GPUs. Featuring custom amber-yellow glass aesthetics, interactive Prompt Auto-Fit expansion, real-time batch evolution, bicubic taskbar icons, and a stealth panic disguise mode (`Ctrl+Space`).

## ✨ Key Features

- ⚡ **Multi-Core CPU Beast Mode:** Automatically unthrottles and harnesses 100% of available CPU cores across all threads.
- 🎨 **Liquid Glass Yellow Theme:** High-contrast amber-gold translucent aesthetic (`#f39c12`) with active glass opacity and wallpaper tinting.
- 🎛️ **Dynamic Prompt Boxes & Auto-Fit:** Prompt, Sticky Prompt, and Negative Prompt boxes with 1-click height expansion to match text length.
- 🕵️ **Panic Disguise Mode (`Ctrl+Space`):** Instantly overlays a simulated PowerShell `Get-Process` (Windows) or `top` (Linux) dashboard for immediate privacy.
- 🐬 **Dolphin 3.0 Integration:** Built-in auto-prompt expansion via local GGUF language models.
- 🛡️ **LGPL Compliance:** Built on PySide6 (The Qt Company official LGPL framework).
